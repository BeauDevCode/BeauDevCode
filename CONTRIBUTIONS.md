# Open-Source Contribution Tracker

This page tracks my public open-source work in a way that is honest and easy for recruiters, maintainers, and reviewers to verify.

## How I Count Contributions

- **Merged** means the maintainer accepted the pull request.
- **Open / ready** means the pull request is public and ready for maintainer review.
- **Draft** means the work still needs final review before I treat it as complete.
- **Closed / not merged** means I submitted the work, but I do not count it as an accepted contribution.
